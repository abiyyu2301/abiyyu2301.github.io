Technical consultant · Singapore

An elder-care nonprofit whose admins could not disable a user account, and nobody knew why. The fix everyone expected was a red herring. The real fault sat a layer deeper, in how the database itself stored dates, and it had been silently rejecting changes in production for months without raising a single error. I traced it, fixed it at the root, and proved it on the live system before calling it done.

Since then I swept 34 dialogs that hung forever whenever a request failed, and shipped the four-phase Befriender workflow. Both repos now deploy on push, so nobody hand-copies a build folder onto the server anymore.
